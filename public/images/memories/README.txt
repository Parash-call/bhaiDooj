The six supplied photos are stored in this folder and shown in the gallery.
Edit their titles and captions in src/data/memories.js.

To add more permanent photos, copy them here and add an entry to
src/data/memories.js with an image path such as:
  /images/memories/your-file-name.jpg

Photos selected with the gallery's Add our photos button are temporary browser
previews; adding a file here makes it part of the project and deployment.
